# Earplug – Ad Mute by Fingerprint
Chrome-расширение: мьютит уже виденные рекламные ролики любой длины по аудио-отпечаткам (Chromaprint).
## Установка
1. Добавьте chromaprint_wasm.js + .wasm (rusty-chromaprint-wasm)
2. chrome://extensions → Режим разработчика → Загрузить распакованное → эта папка
